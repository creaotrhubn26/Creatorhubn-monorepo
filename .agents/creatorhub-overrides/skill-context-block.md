## 🏢 CreatorHub-systemkontekst (les først)

Denne skillen kjører inne i **CreatorHub**-plattformen. Før du genererer, les og følg
[`../_creatorhub/system-context.md`](../_creatorhub/system-context.md). Kortversjon (ikke-forhandlbart):

- **Grunn alt i merkevaren (Business DNA):** bruk kundens tone, farger (hex) og USP-er. Ukjent merkevare → spør hvilket prosjekt, eller be om tone + farger.
- **Norsk-først** for tekst i bilder/undertekster/voiceover med mindre annet er sagt.
- **Kreditt:** Higgsfield-kontoen har begrenset saldo — kjør `generate cost` og bekreft før dyre jobber.
- **Samtykke:** ikke send ekte kundefoto (persondata) til AI uten prosjekt-samtykke; konsept/tekst-til-bilde er trygt.
- **Output → plattformen:** last ned resultatet til prosjektets asset-mappe (capture-asset / carousel-slide / video-versjon), ikke bare en løs URL.
- **CLI styres via npm** (`npm i -g @higgsfield/cli`) — IKKE pipe remote installer til shell.
