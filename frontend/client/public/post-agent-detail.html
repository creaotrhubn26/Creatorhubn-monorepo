Post Agent

AI-drevet post-produksjons-assistent for DaVinci Resolve. Cull, scene-detection, beat-synket music-video, transkripsjon — kjører lokalt på Mac-en og snakker direkte med Resolve.

  • AI cull (Claude Vision) — automatisk klipp-utvelgelse, sparer 60-80% av tiden
  • Highlight-scoring per klipp + scene-tagging
  • Beat-synket music-video pipeline (librosa beat-detection)
  • WhisperX transkripsjon — lokalt på Mac-en, ingen cloud-upload
  • Multi-cam organize + color grouping
  • Mac native — krever DaVinci Resolve Studio

Slik fungerer det

  1. 1
    Konfigurer prosjektet i Role Room
    Legg til scener, utstyr (kamera/lyd) og crew. Post Agent leser dette automatisk når den parer.
  2. 2
    Aktiver tilgang for crew
    Du som lead bestemmer hvem som får tilgang — 299 NOK/seat/mnd. Stripe pro-ratar når du legger til eller fjerner medlemmer.
  3. 3
    Crew parer Mac-en sin med Role Room
    Installerer Post Agent.app, logger inn med Role Room-kontoen — appen ser umiddelbart prosjektets scener, utstyr og fangede klipp.
  4. 4
    AI-drevet post-produksjon i DaVinci Resolve
    Pre-genererer bins per scene · auto-konfigurerer Resolve etter kamera-utstyret · cull med Claude Vision · beat-sync · transkripsjon. Alt lokalt — ingen filer forlater Mac-en.
  5. 5
    Live Set-handoff
    Klipp som fanges under shoot dukker opp i Post Agent med scene-metadata intakt — klare for ingest med ett klikk.
