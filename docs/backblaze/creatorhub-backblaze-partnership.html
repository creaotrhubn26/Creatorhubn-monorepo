What we've built — production today

The B2 integration is fully implemented and deployed to creatorhub-backend-rtbl.onrender.com. We can demo it live on the call.

  • 30-second onboarding — users connect B2 credentials via guided flow
  • Encrypted storage — AES-256-GCM with HKDF-derived per-user keys
  • Automatic mirroring — uploads to galleries, marketing, and masters are mirrored to user's B2 bucket
  • 6-hourly background sync — keeps CreatorHub UI in sync with B2 state
  • Per-user dashboard — file browser, usage stats, cost projection
  • S3-compatible — works with B2's existing API, no special SDK needed
